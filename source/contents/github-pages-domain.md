# GitHub Pages와 커스텀 도메인 연결기

GitHub Pages는 저장소에 있는 정적 파일을 웹사이트로 공개해 줍니다. 별도의 서버를 운영하지 않아도 커밋한 내용이 사이트에 반영된다는 점이 가장 큰 장점입니다.

## 배포 흐름

1. 저장소 설정에서 Pages 배포 브랜치를 선택합니다.
2. 사이트 루트에 `index.html`이 있는지 확인합니다.
3. 변경 파일을 커밋하고 GitHub에 푸시합니다.
4. Actions 또는 Pages 화면에서 배포 완료 여부를 확인합니다.

## 도메인 연결

저장소의 `CNAME` 파일에는 사용할 도메인을 한 줄로 기록합니다. 도메인 관리 화면에서는 GitHub Pages가 안내하는 IP 또는 호스트를 DNS 레코드에 연결합니다.

## HTTPS 확인

DNS 변경은 바로 반영되지 않을 수 있습니다. 도메인 연결이 확인된 뒤 HTTPS 옵션을 활성화하고, `http` 주소가 `https`로 안전하게 이동하는지 점검합니다.
