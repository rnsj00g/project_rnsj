# 마이크로러닝 콘텐츠 제작 실험

긴 강의를 단순히 여러 조각으로 자른다고 마이크로러닝이 되지는 않습니다. 짧은 시간 안에 하나의 분명한 변화를 만들 수 있도록 내용을 다시 설계해야 합니다.

## 실험 기준

각 학습 단위를 5분 안에 완료할 수 있게 만들고, 시작할 때 목표를 한 줄로 보여주었습니다. 설명 뒤에는 반드시 판단하거나 직접 해보는 활동을 배치했습니다.

## 관찰한 변화

- 학습 시작에 대한 부담이 줄었습니다.
- 중단 후 다시 돌아올 위치가 명확해졌습니다.
- 짧은 확인 문제를 통해 오해를 빠르게 발견할 수 있었습니다.

## 남은 과제

학습 단위가 너무 잘게 나뉘면 전체 맥락을 놓칠 수 있습니다. 여러 단위가 하나의 큰 목표로 어떻게 이어지는지 보여주는 진행 지도와 요약 화면이 함께 필요합니다.
