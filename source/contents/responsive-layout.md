# 반응형 포트폴리오의 레이아웃 원칙

반응형 디자인의 목표는 화면마다 완전히 다른 사이트를 만드는 것이 아닙니다. 콘텐츠의 우선순위는 유지하면서 사용할 수 있는 공간에 맞게 흐름을 바꾸는 것입니다.

## 콘텐츠부터 정렬하기

가장 먼저 읽어야 할 제목, 내용을 구분하는 메타 정보, 다음 행동을 돕는 링크 순서로 구조를 잡았습니다. 화면이 작아져도 이 순서는 바뀌지 않습니다.

## 유연한 크기 사용하기

고정된 픽셀값 대신 `clamp()`와 그리드를 사용했습니다. 제목은 화면 폭에 따라 자연스럽게 변하고, 카드 배열은 데스크톱의 여러 열에서 모바일의 한 열로 전환됩니다.

1. 넓은 화면에서는 카드의 크기에 변화를 줍니다.
2. 태블릿에서는 두 열을 유지합니다.
3. 모바일에서는 읽기 편한 한 열로 정리합니다.

## 실제 문장으로 확인하기

짧은 샘플 텍스트만 사용하면 줄바꿈 문제를 놓치기 쉽습니다. 실제 제목과 설명을 넣고 한글의 어절이 어색하게 분리되지 않는지 확인하는 과정이 필요합니다.
