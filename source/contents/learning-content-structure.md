# 학습자가 길을 잃지 않는 콘텐츠 구조

학습 콘텐츠는 정보가 정확한 것만으로 충분하지 않습니다. 학습자가 지금 무엇을 배우고 있고, 다음에 무엇을 해야 하는지 계속 알 수 있어야 합니다.

## 목표에서 시작하기

먼저 학습을 마친 사람이 실제로 할 수 있어야 하는 행동을 한 문장으로 정의합니다. 그 행동에 필요하지 않은 정보는 본문에서 덜어내거나 참고 자료로 분리합니다.

## 하나의 화면, 하나의 질문

각 화면은 하나의 핵심 질문에 답하도록 구성합니다. 제목을 질문처럼 읽어도 내용의 방향을 예상할 수 있다면 구조가 잘 잡힌 것입니다.

- 개념을 짧게 설명합니다.
- 실제 상황의 예시를 보여줍니다.
- 작은 활동으로 이해 여부를 확인합니다.
- 다음 내용과의 연결을 안내합니다.

## 반복 가능한 패턴

같은 유형의 정보는 같은 위치와 형식으로 제시합니다. 익숙한 패턴은 탐색에 쓰이는 인지 부담을 줄이고, 학습 내용 자체에 집중하도록 돕습니다.
